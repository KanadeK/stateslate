# StateSlate

**Compile story continuity into shoot-day reset sheets.**

StateSlate is an offline, dependency-free continuity compiler for small film,
video, and photo productions. It propagates explicitly declared wardrobe,
props, hair, makeup, set, and other states in story order, then projects them
into shoot order to produce setup states, reset actions, and missing-reference
risks.

StateSlate does not parse scripts, judge photos, or prove physical continuity.
The full v0.1 contract is in [SPEC.md](SPEC.md); implementation is in progress.
